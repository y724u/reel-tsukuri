# リール作り

Claude アプリの「コード」で、Instagram リールの台本づくりと動画づくりを Claude に任せるためのプラグインです。

1. Claude アプリの「コード」で、入力欄の横の「+」から「Plugins」を開き、このリポジトリ（y724u/reel-tsukuri）を追加して、reel-tsukuri を入れる
2. 「リール作りの準備をして」と送る。ムービーの中に「リール作り」フォルダができ、決まりのファイルが置かれます。動画づくりに要る道具（ffmpeg と Pillow）も確かめ、足りなければ入れ方を説明します
3. 新しい会話で「リール作り」フォルダを選び、「台本を作って」か「動画を作って。（フォルダの名前）」と送る
