# リール作りの準備

作業フォルダ「リール作り」に、決まりのファイル3つを置く（すでにあれば最新に入れ替える）。

1. 置き場所を決める。今開いているフォルダの名前が「リール作り」なら、そこを使う。そうでなければ、ホームの「ムービー」（~/Movies）の中の「リール作り」を使い、無ければ作る
2. ${CLAUDE_SKILL_DIR}/kit/ にある次の3つを、置き場所にコピーする。同じ名前のファイルがあれば上書きする（どれも決まりのファイルで、利用者のデータではない）
   - CLAUDE.md
   - Claudeへの指示書_1_台本づくり.txt
   - Claudeへの指示書_2_動画づくり.txt
3. ほかのファイルやフォルダ（素材のフォルダ・台本.txt・撮影リスト.txt・完成した動画・テロップの見本の画像）には触らない。消さない・動かさない・上書きしない
4. 終わったら、置き場所と、置いた3つのファイルの名前を短く伝える。続けて、次のように伝える:「新しい決まりは、新しい会話から使えます。Claude アプリの『新規セッション』で、このフォルダ（リール作り）を選んでから、『台本を作って』か『動画を作って。（フォルダの名前）』と送ってください」
