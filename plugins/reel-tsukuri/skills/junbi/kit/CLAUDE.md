# このフォルダについて

Instagram リールを作るための作業場所です。指示書が2つ入っています。

- Claudeへの指示書_1_台本づくり.txt
- Claudeへの指示書_2_動画づくり.txt

## 頼まれたら
- 「台本」を頼まれたら、指示書_1 を読んで、書いてあるとおりに進める
- 「動画」や「リール」を作ってと頼まれたら、指示書_2 を読んで、書いてあるとおりに進める
- どちらか分からないときは、どちらにするか聞く
- ソフトや道具を新しく入れるときは、何を入れるかを説明して、私の OK を待ってから入れる（どの頼まれごとでも同じ）

## このフォルダでの決まり（指示書と食い違うときは、こちらを優先）
- 1本のリールにつき、このフォルダの中のフォルダを1つ使う（例: 2026-11_物件の名前）
- 台本づくりの1つ目の質問（物件のこと）では、物件の名前も聞く
- 台本を出したら、このフォルダの中に「年-月_物件の名前」のフォルダを作り、台本の行を「台本.txt」、撮影リストを「撮影リスト.txt」として保存する。新しく作るときに同じ名前のフォルダがすでにあれば、上書きせず、名前の後ろに _2、_3 と付けた新しいフォルダにする。保存したら、そのフォルダを Finder で開いて（open コマンド）、「撮った動画は、このフォルダに入れてください。入れ終わったら『動画を作って。（フォルダの名前）』と送ってください」と伝える
- 台本を直してと頼まれたら（別の会話でも）、そのリールのフォルダの台本.txt と撮影リスト.txt を上書きする。新しく作るのか直すのか分からなければ聞く
- 自分で書いた台本を渡されて、形を整えてと頼まれたら、指示書_1 の質問からは始めない。指示書_2 の台本の形（1行に1カット。「開始秒-終了秒　画／テロップ」）に整えて見せ、秒数・画・テロップで足りない所だけ聞く。OK をもらってから、素材のフォルダの「台本.txt」として保存する（どのフォルダか分からなければ聞く）
- 「素材を入れるフォルダを作って」と頼まれたら、物件の名前を聞いて（言われていればそれを使う）、このフォルダの中に「年-月_物件の名前」のフォルダを作り（同じ名前があればそれを使う）、Finder で開いて（open コマンド）、「撮った動画をこのフォルダに入れてください。台本があれば、台本.txt も一緒に入れてください。入れ終わったら『動画を作って。（フォルダの名前）』と送ってください」と伝える
- 「動画を作って」と頼まれたときに、使える素材のフォルダが無い（この中にフォルダが無い・言われた名前のフォルダが無い・フォルダに動画が1本も無い）ときは、作業を始めない。すぐ上の「素材を入れるフォルダを作って」と同じようにフォルダを用意して開き、伝えて止まる
- 動画づくりの「最初にすること」の3つは、このフォルダで分かるものは聞かずに使う
  1. 素材のフォルダ: 頼まれたときにフォルダの名前を言われたら、それを使う。言われなければ、この中のフォルダの名前を並べて、どれか聞く（名前が「_完成」で終わるフォルダは並べない）
  2. 台本: その素材のフォルダに「台本.txt」があれば、それを使う
  3. テロップの見本: このフォルダのすぐ下に画像（スクリーンショット）が1枚あれば、それを見本にする。2枚以上あれば、どれか聞く。無ければ「なし」
- 3つとも分かったら、聞かずに進め方の1から始める。カット表を出すときは、その最初に「この3つで作ります」と書いて、使った素材のフォルダ・台本（中身も）・テロップの見本を並べる。分からないものがあれば、作業を始める前に、それだけをまとめて1回で聞く
- テロップの見本があるときは、指示書_2 の「テロップの見た目」にある書体・太さ・色・ストロークなしの決まりより見本を優先し、字の形（明朝かゴシックか・太さ）・色・フチ・影・帯・大きさ・字間・縦書きか横書きかを、見本に忠実に合わせる。横書きのときは、指示書_2 の「列」を「行」と読み替える。カット表の最初の「この3つで作ります」には、見本から読み取った見た目も書く（例: 角ゴシックの太字・黄色・黒いフチ・右下に影）。見本が「なし」のときは、指示書_2 のとおりにする
- 3つを確かめるために、このフォルダの中のフォルダの名前を見ること・台本.txt を読むこと・見本の画像を開くことはしてよい
- Python で画像を扱うときは、Pillow が入っている python3 を使う（`python3 -c "import PIL"` が通るもの。通らなければ /usr/bin/python3 と /opt/homebrew/bin/python3 も試す）。どれにも無ければ、入れる前に説明して OK を待つ
- 素材や資料を探しに、このフォルダの外を見に行かない（フォントやソフトなど、作業に要るものは使ってよい）
