# このフォルダについて

Instagram リールを作るための作業場所です。指示書が2つ入っています。

- Claudeへの指示書_1_台本づくり.txt
- Claudeへの指示書_2_動画づくり.txt

## 頼まれたら
- 台本や動画を頼まれたら、作業の前に、決まりのファイル3つを GitHub の最新にする。次をそのまま実行する（D はこの CLAUDE.md があるフォルダのフルパス）。取れたら、この CLAUDE.md と指示書を読み直して、新しい決まりで進める（読み直したあとは、この「最新にする」は繰り返さない。1つの会話で1回だけ）。エラーで取れなかったときや、アプリに止められたときは（3つとも取れたときだけ入れ替わるので、手元のファイルは元のまま）、別のやり方で取りに行かず、「最新を取れなかったので、手元の決まりで進めます」と1行伝えて、手元のファイルで進める
```bash
D="（この CLAUDE.md があるフォルダのフルパス）"
B="https://raw.githubusercontent.com/y724u/reel-tsukuri/main/plugins/reel-tsukuri/skills/junbi/kit"
mkdir -p "$D/.dl" && \
curl -fsSL "$B/CLAUDE.md" -o "$D/.dl/1" && \
curl -fsSL "$B/Claude%E3%81%B8%E3%81%AE%E6%8C%87%E7%A4%BA%E6%9B%B8_1_%E5%8F%B0%E6%9C%AC%E3%81%A5%E3%81%8F%E3%82%8A.txt" -o "$D/.dl/2" && \
curl -fsSL "$B/Claude%E3%81%B8%E3%81%AE%E6%8C%87%E7%A4%BA%E6%9B%B8_2_%E5%8B%95%E7%94%BB%E3%81%A5%E3%81%8F%E3%82%8A.txt" -o "$D/.dl/3" && \
mv "$D/.dl/1" "$D/CLAUDE.md" && \
mv "$D/.dl/2" "$D/Claudeへの指示書_1_台本づくり.txt" && \
mv "$D/.dl/3" "$D/Claudeへの指示書_2_動画づくり.txt" && echo "最新にしました"
```
- 「台本」を頼まれたら、指示書_1 を読んで、書いてあるとおりに進める
- 「動画」や「リール」を作ってと頼まれたら、指示書_2 を読んで、書いてあるとおりに進める
- どちらか分からないときは、どちらにするか聞く
- 道具の Pillow と ffmpeg（imageio-ffmpeg）は、無ければ聞かずに入れる（下の「道具」のとおり）。それ以外のソフトや部品は入れない。要りそうなときは、何が要るかを1行で伝えて止まる
- 指示書とこのファイルに書いてある進め方は、聞かずにそのとおりに進める。進め方の中で選ぶこと（どのカットを使うか・テロップの位置など）は、指示書のとおりに案を出して確かめる
- 進め方そのものを変えることは、自分で決めない。たとえば、手順を飛ばす・別のやり方に切り替える・書いていないソフトや部品を入れる・設定を変える・素材や資料をこのフォルダの外から使う・このフォルダの外にファイルを作る、消す（道具を入れる pip のコマンドと、道具・フォントを使うことは除く）。うまくいかないとき（エラーで終わった・アプリに止められた）も、別のやり方を自分で試さない。何が起きたかと、次にしたいことを1〜2行で伝えて、私の OK を待つ

## このフォルダでの決まり（指示書と食い違うときは、こちらを優先）
- 1本のリールにつき、このフォルダの中のフォルダを1つ使う（例: 2026-11_物件の名前）
- 台本づくりの1つ目の質問（物件のこと）では、物件の名前も聞く
- 台本を出したら、このフォルダの中に「年-月_物件の名前」のフォルダを作り、台本の行を「台本.txt」、撮影リストを「撮影リスト.txt」として保存する。同じ名前のフォルダがすでにあっても、中に台本.txt が無ければ（素材を入れるために先に作ったフォルダ）、そのフォルダに保存する。台本.txt があるときだけ、上書きせず、名前の後ろに _2、_3 と付けた新しいフォルダにする。保存したら、そのフォルダを Finder で開いて（open コマンド）、「撮った動画は、このフォルダに入れてください。入れ終わったら『動画を作って。（フォルダの名前）』と送ってください」と伝える
- 台本を直してと頼まれたら（別の会話でも）、そのリールのフォルダの台本.txt と撮影リスト.txt を上書きする。新しく作るのか直すのか分からなければ聞く
- 自分で書いた台本を渡されて、形を整えてと頼まれたら、指示書_1 の質問からは始めない。指示書_2 の台本の形（1行に1カット。「開始秒-終了秒　画／テロップ」）に整えて見せ、秒数・画・テロップで足りない所だけ聞く。OK をもらってから、素材のフォルダの「台本.txt」として保存する（どのフォルダか分からなければ聞く）
- 「素材を入れるフォルダを作って」と頼まれたら、物件の名前を聞いて（言われていればそれを使う）、このフォルダの中に「年-月_物件の名前」のフォルダを作り（同じ名前があればそれを使う）、Finder で開いて（open コマンド）、「撮った動画をこのフォルダに入れてください。台本があれば、台本.txt として一緒に入れるか、この会話に貼ってください。テロップの見た目を合わせたいリールがあれば、そのスクリーンショットを1枚、リール作りのフォルダ（CLAUDE.md と同じ場所）に入れてください。入れ終わったら『動画を作って。（フォルダの名前）』と送ってください」と伝える
- 「動画を作って」と頼まれたときに、使える素材のフォルダが無い（この中にフォルダが無い・言われた名前のフォルダが無い・フォルダに動画が1本も無い）ときは、作業を始めない。すぐ上の「素材を入れるフォルダを作って」と同じようにフォルダを用意して開き、伝えて止まる
- 動画づくりの「最初にすること」の3つは、このフォルダで分かるものは聞かずに使う
  1. 素材のフォルダ: 頼まれたときにフォルダの名前を言われたら、それを使う。言われなければ、動画が入っているフォルダ（名前が「_完成」で終わるフォルダは除く）が1つだけならそれを使う。2つ以上あれば、名前を並べてどれか聞く
  2. 台本: その素材のフォルダに「台本.txt」があれば、それを使う。無ければ、作業を始める前の質問で「台本をこの会話に貼るか、台本.txt としてこのフォルダ（素材のフォルダ）に入れてください。まだ台本が無ければ『台本を作って』と送ってください」と伝える
  3. テロップの見本: このフォルダのすぐ下に画像（スクリーンショット）が1枚あれば、それを見本にする。2枚以上あれば、どれか聞く。無ければ「なし」として、聞かずに進める（いつもの白い明朝）。そのときは、カット表の「この3つで作ります」に「見本なし（いつもの白い明朝）。見本に合わせたいときは、合わせたいリールのスクリーンショットを1枚、リール作りのフォルダ（CLAUDE.md と同じ場所）に入れて『見本に合わせて作り直して』と送ってください」と書く
- 3つとも分かったら、聞かずに進め方の1から始める。カット表を出すときは、その最初に「この3つで作ります」と書いて、使った素材のフォルダ・台本（中身も）・テロップの見本を並べる。分からないものがあれば、作業を始める前に、それだけをまとめて1回で聞く
- テロップの見本があるときは、指示書_2 の「テロップの見た目」にある書体・太さ・色・ストロークなしの決まりより見本を優先し、字の形（明朝かゴシックか・太さ）・色・フチ・影・帯・大きさ・字間・縦書きか横書きかを、見本に忠実に合わせる。横書きのときは、指示書_2 の「列」を「行」と読み替える。カット表の最初の「この3つで作ります」には、見本から読み取った見た目も書く（例: 角ゴシックの太字・黄色・黒いフチ・右下に影）。見本が「なし」のときは、指示書_2 のとおりにする
- 見本として Instagram などのリールの URL を渡されたときは、ログインしないと中身が見えず読めないことが多いので、「そのリールのテロップが映っている所のスクリーンショットを1枚、リール作りのフォルダ（CLAUDE.md と同じ場所）に入れてください」と頼む
- 3つを確かめるために、このフォルダの中のフォルダの名前を見ること・台本.txt を読むこと・見本の画像を開くことはしてよい
- 道具: Python は /usr/bin/python3 を使う（Pillow はここに入れてある）。ffmpeg は `/usr/bin/python3 -c "import imageio_ffmpeg; print(imageio_ffmpeg.get_ffmpeg_exe())"` で出る場所のものを、いつも使う（`ffmpeg` コマンドや ffprobe があっても使わない。Mac によって版がちがうと、結果が変わるため）。この ffmpeg には ffprobe が付いていないので、動画の長さ・向き・大きさは「その ffmpeg -i ファイル」の表示から読む（出力先を付けないので終了コードは1になるが、表示が読めればエラーではない）。どちらかが無ければ、聞かずに `/usr/bin/python3 -m pip install --user --disable-pip-version-check -q pillow imageio-ffmpeg` で入れる。Homebrew・ターミナル・sudo・Mac のパスワードを使うやり方はしない
- 素材を見るときは、1本につき2〜4枚の縮小した静止画（横 360px ほど）で見る。全部のフレームを画像にしない。素材の処理は1本ずつ行い、同時にいくつも動かさない
- テロップの画像は Pillow で作る（Chrome などのブラウザは使わない）。縦書きは、1文字ずつ上から並べて作る（Pillow の direction="ttb" は使えないことがあるので使わない）。「ー」「〜」は縦向きに回し、「、」「。」は字の右上に寄せ、かっこ・かぎかっこは縦書きの向きにする
- 書体は /System/Library/Fonts/ の「ヒラギノ明朝 ProN.ttc」を使う。太字（W6）は index=2。見本に合わせてゴシックにするときは、同じ場所の「ヒラギノ角ゴシック W（太さの数字）.ttc」を使う
- 書き出しは H.264（libx264）・yuv420p・30fps・-preset veryfast・-crf 20 にする。H.265（HEVC）では書き出さない
- iPhone の素材には「回して表示する」印（rotate・displaymatrix）が付いていることが多い。完成品には回転の印を残さず、画そのものを正しい向きにして書き出す。書き出したら「その ffmpeg -i 完成品」の表示に rotate や displaymatrix が出ないことと、縦 1080×1920 であることを確かめる
- 作業用のファイルは消さない（rm を使わない）。作り直すときは同じ名前で上書きする
- 素材や資料を探しに、このフォルダの外を見に行かない（フォントやソフトなど、作業に要るものは使ってよい）
